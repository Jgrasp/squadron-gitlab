# Changelog

## 0.2.0 · 2026-11-20

- Merging a merge request offers squash or not, as the project allows it, and whether to delete the source branch
- Merge requests tell whether their source branch is protected, so that GitLab keeps it after the merge

## 0.1.0 · 2026-11-20

- Merge requests of your GitLab projects in Squadron, on gitlab.com or your own server: the merge request of each agent's branch, the ones to review, yours and the others, with their pipeline and reviewers
- Reviews with line comments, a summary and an approval, replies to remarks, resolved threads shown and resolved from Squadron, merges, and title and description changes
- Pipelines of each project, with a notification when one ends
- Pipelines run on a merge request show its number and title and are filed under PR checks
- Chips for GitLab merge request links in conversations
- GitLab accounts with a server address and a personal access token checked before it is saved
